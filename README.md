# Leuchtwald

Sieben kurze Konzentrationsspiele für Kinder (Impulse bremsen, umdenken, merken, Ablenkung ausblenden, suchen, dranbleiben, atmen) mit Verlauf.

- Läuft komplett im Browser, keine Anmeldung, keine Server.
- Sterne und Verlauf bleiben nur im Browser des jeweiligen Geräts.
- Auf dem iPad in Safari öffnen und über „Teilen → Zum Home-Bildschirm“ wie eine App starten.

Die Spiele üben Fähigkeiten im Spiel. Sie ersetzen keine Diagnostik, Therapie oder ärztlich verordnete Behandlung.
